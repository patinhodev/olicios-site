# Política de segurança

## Versão suportada

A versão publicada na branch principal recebe correções de segurança.

## Como comunicar uma vulnerabilidade

Não publique detalhes sensíveis em uma issue pública. Utilize a opção **Report a vulnerability** na aba **Security** do repositório para abrir um GitHub Private Vulnerability Report. Caso esse recurso não esteja habilitado, entre em contato diretamente com o responsável pelo repositório.

Inclua, quando possível:

- descrição e impacto esperado;
- etapas mínimas para reprodução;
- URL, arquivo ou componente afetado;
- sugestão de correção, se houver.

Não execute testes destrutivos, indisponibilidade, engenharia social ou acesso a dados de terceiros. Toda análise deve ocorrer com autorização e dentro do escopo definido.
